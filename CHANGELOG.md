# Changelog

All notable changes to this project are documented here. Releases are generated by `npm run release`.

## 0.1.3

- The default voice id is now `readaloud-default`. Workflows that use the earlier default voice id keep working. The package description, README and examples list only voice name, language, dialect and tier.

## 0.1.2

- Author contact email changed to a monitored address (support@readaloudai.org) so n8n's ownership verification email can be delivered. No code changes.

## 0.1.1

- First release published from GitHub Actions with npm provenance (trusted publishing).
- Removed the Voice > Get Many operation: only `readaloud-default` is offered for now, so there is no list to show.

## 0.1.0

- Initial release.
- Speech resource: Text to Speech (MP3, WAV, Opus, PCM; speed 0.25 to 4; custom voice, model, file name and binary property).
- Voice resource: Get Many.
- ReadAloud API credential with Bearer authentication and a connection test.
